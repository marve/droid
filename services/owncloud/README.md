# Purpose
Self-hosted file hosting and synchronisation using [OwnCloud](https://owncloud.com/).

> **Note:** This service is currently disabled (a `disable` file is present). To enable it, remove the `disable` file and re-run `apply.sh`.

# Usage
Once enabled, the web interface is available at `http://your-host-ip:8080`. Default credentials are configured in `.env`; change them before exposing the service to a network.
